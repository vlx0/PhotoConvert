# PhotoConvert

**День 89 / 365 · неделя 13 — «Софт» · darkshade (@vlx0)**

Пакетный конвертер файлов для Windows. Добавьте файлы, выберите формат и папку для результата. Список форматов зависит от добавленных файлов. В смешанной партии несовместимые файлы помечаются как пропущенные. Двойной щелчок показывает путь к результату или причину ошибки.

- **Изображения** — PNG, JPG, BMP, WebP, GIF, TIFF, ICO и AVIF, если формат доступен в установленной сборке Pillow. Читаются также PPM, PGM и TGA. Поддерживаются однокадровые изображения до 40 Мп и 256 МиБ. Прозрачность JPG и BMP заменяется белым фоном. ICO уменьшается до 256×256 с сохранением пропорций.
- **Аудио** — WAV, FLAC, MP3, OGG (Opus) и M4A (AAC). Из видео можно извлечь первую звуковую дорожку.
- **Видео** — перенос дорожек аудио и видео в контейнер MKV или MP4 без перекодирования. Совместимость зависит от исходных кодеков. Субтитры и вложения не переносятся.
- **Таблицы** — CSV с запятой, TSV, табличный JSON и XLSX с одним листом. Читается и TOML с одним массивом таблиц. Сохраняются значения ячеек или текст формул. Оформление таблиц не переносится.
- **Документы** — текст из DOCX, HTML, TXT, Markdown, LOG и PDF с текстовым слоем сохраняется в TXT, HTML или DOCX. Вёрстка, изображения и оформление не переносятся. OCR не используется.
- **Архивы** — любой файл можно упаковать отдельно в ZIP, GZ, BZ2 или XZ.

При совпадении имён добавляется номер. Готовый файл публикуется только после завершения записи. Два файла могут обрабатываться одновременно. Остановка сохраняет результаты, которые уже успели записаться. Некоторые операции кодека нельзя прервать посередине, поэтому окно ждёт их завершения.

## Запуск

Windows и Python 3.12+ с tkinter. Конвертация идёт в процессе Python через установленные пакеты. Pillow и PyAV включают нативные кодеки. PowerShell и отдельный ffmpeg.exe не нужны.

```bat
python -m pip install --target _vendor -r requirements.txt
pythonw -m photoconvert
```

После установки можно запускать через `start.bat`. Локальная папка `_vendor` не входит в репозиторий. Лицензия проекта MIT.
